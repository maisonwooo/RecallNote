# 화면 목록 (docs/screens.md)

## 전체 화면 한눈에
| # | 화면 | 주소 | 하는 일 |
|---|---|---|---|
| 1 | 홈(오늘) | `/` | 오늘 복습할 장수, 오늘 집중 시간, 바로가기 |
| 2 | 복습 | `/review` | 카드 한 장씩 복습, 끝나면 결과 요약. 상한을 채우면 `?extra=1`(더 복습하기, 최대 10장) |
| 3 | 카드 목록 | `/cards` | 검색, 태그 거르기, 최근 순 |
| 4 | 카드 만들기 | `/cards/new` | 질문·답·출처·태그 입력 |
| 5 | 카드 보기 | `/cards/[id]` | 보기, 수정·삭제 버튼 (삭제는 확인 창 후 보관함으로) |
| 5-1 | 카드 수정 | `/cards/[id]/edit` | 수정 폼 |
| 6 | 보관함 | `/archive` | 삭제한 카드 복원 |
| 7 | 타이머 | `/timer` | 집중/휴식, 눈 휴식 안내 |
| 8 | 통계 | `/stats` | 오늘·이번 주 집중 시간, 주간 막대 그래프 |
| 9 | 백업 | `/backup` | JSON 내보내기/가져오기(미리보기), CSV 내보내기 |
| 10 | 설정 | `/settings` | 복습 상한, 타이머 시간, 글자 크기 |

공통: 위쪽 메뉴로 홈·복습·카드·보관함 이동(타이머·통계·백업·설정은 해당 단계에서 추가).

## 화면별 배치

### 1. 홈
```
┌───────────────────────────────┐
│ RecallNote      홈 카드 타이머 … │
├───────────────────────────────┤
│ 오늘 복습할 카드   12 / 20장     │
│ [ 복습 시작 ]                   │
│                                │
│ 오늘 집중 시간    1시간 40분     │
│ [ 타이머 열기 ]  [ 카드 추가 ]   │
└───────────────────────────────┘
```

### 2. 복습 (한 장씩)
```
 3 / 12                      [나가기]
┌───────────────────────────────┐
│  질문                           │
│  솔트(salt)는 왜 쓰나요?         │
│                                │
│        [ 답 보기 (Space) ]      │
└───────────────────────────────┘
↓ 답 보기 후
│  내가 쓴 답: …  출처: 2주차 3회  │
│ [1 틀림]  [2 애매]  [3 맞음]    │
```
끝나면: `맞음 8 / 애매 3 / 틀림 1` 요약.

### 3. 카드 목록
```
[ 검색: ______ ]  태그: [git] [http] …   [+ 새 카드]
────────────────────────────────
Q. 솔트는 왜 쓰나요?        #보안  상자2
Q. 상태코드 404 의미?       #http  상자1
```

### 4·5. 카드 만들기/수정
질문(여러 줄) / 답(여러 줄) / 출처(선택) / 태그(쉼표로 여러 개) / [저장] [취소] (5번은 [삭제] 추가, 확인 창 표시)

### 6. 보관함
삭제한 카드 목록 + [복원]. (완전 삭제 기능은 지금 만들지 않음)

### 7. 타이머
```
        집중 중
        42:15        ← 시작 시각으로 계산, 새로고침해도 유지
   [ 시작 ] [ 중지 ]

휴식 때: 큰 글씨로 "먼 곳을 20초 바라보세요"
```

### 8. 통계
오늘/이번 주 합계 + 7일 막대 그래프(요일별 집중 분).

### 9. 백업
[전체 JSON 내보내기] / [JSON 가져오기 → 미리보기(카드 N장, 태그 N개…) → 확인] / [카드 CSV 내보내기]

### 10. 설정
하루 복습 상한 / 집중·휴식 분 / 글자 크기 / (동작 줄이기는 시스템 설정을 따름)
