# RecallNote

배운 개념을 **"질문/답" 카드**로 저장하고, 잊을 때쯤 다시 보여 주고, 공부 시간과 눈 휴식까지 챙겨 주는 **내 컴퓨터 안에서만 도는 학습 노트 앱**입니다.

- 🔒 **로컬 전용**: 로그인도 회원가입도 없고, 데이터를 밖으로 보내지 않습니다. 모든 기록은 내 컴퓨터의 파일 하나에만 저장됩니다.
- 🧠 **간격 반복 복습**: 맞히면 복습 간격이 1 → 2 → 4 → 8 → 16일로 늘어나고, 틀리면 처음으로 돌아갑니다.
- ⏱️ **공부 타이머**: 집중 시간 뒤에 눈 휴식을 안내합니다.
- 💾 **백업**: 파일로 내보내고 가져올 수 있고, (macOS) 자동 백업도 켤 수 있습니다.

> 기획과 설계 내용은 [spec.md](spec.md)에 있습니다.

## 1. 설치와 실행

### 필요한 것
- **Node.js 22.5 이상** ([nodejs.org](https://nodejs.org)에서 받을 수 있어요.) 데이터베이스(SQLite)는 Node에 들어 있어서 따로 설치할 것이 없습니다.
- 터미널(맥은 "터미널" 앱, 윈도우는 "PowerShell")

### 실행 3단계
```
npm install        # 1) 필요한 부품 설치 (처음 한 번만)
npm run dev        # 2) 앱 켜기
```
3) 브라우저에서 **http://127.0.0.1:3000** 을 엽니다. 터미널에 다른 주소가 나오면 그 주소를 여세요.

처음 열면 빈 데이터 파일(`data/recallnote.db`)이 자동으로 만들어집니다. 끌 때는 터미널에서 `Ctrl + C`를 누르세요.

> 이 앱은 `127.0.0.1`(내 컴퓨터 안에서만 열리는 주소)로만 열립니다. 같은 와이파이의 다른 기기에서는 접속되지 않고, 이것은 일부러 막아 둔 것입니다.

## 2. 처음 써 보기

### 예시 카드로 먼저 둘러보기 (선택)
내 진짜 기록과 섞이지 않게 **연습용 파일**을 따로 만들어 쓰는 방법입니다.
```
RECALLNOTE_DB_PATH=/tmp/practice.db npm run db:seed
RECALLNOTE_DB_PATH=/tmp/practice.db npm run dev
```
예시 카드 6장이 들어간 상태로 열립니다. (윈도우는 이 방식의 환경변수 지정이 달라서, 그냥 빈 상태에서 시작하는 것을 권합니다.)

### 기본 사용 순서
1. **카드 만들기**: `/cards/new`에서 질문과 답을 적고 태그를 붙입니다.
2. **복습하기**: `/review`에서 오늘 복습할 카드가 한 장씩 나옵니다.
3. **공부하기**: `/timer`에서 집중 시간을 시작하면 끝날 때 휴식을 알려 줍니다.

### 복습 키보드
| 키 | 하는 일 |
|---|---|
| `Space` | 답 보기 |
| `1` | 틀림: 1번 상자로 돌아가 내일 다시 나옵니다 |
| `2` | 애매: 같은 상자에 머물고, 그 상자의 간격만큼 뒤에 다시 나옵니다 |
| `3` | 맞음: 다음 상자로 올라가 간격이 늘어납니다 |

하루에 복습하는 카드 수는 기본 20장입니다. 다 하면 "더 복습하기"(10장씩)를 누를 수 있어요.

화면은 컴퓨터의 **다크/라이트 설정**을 그대로 따릅니다.

## 4. ⚠️ 백업 (꼭 읽어 주세요)

**DB 파일은 git에 없으니 가끔 백업하세요.**
`data/` 폴더와 `*.db`는 개인 학습 기록이라 일부러 git에서 뺐습니다. 컴퓨터가 고장 나거나 폴더를 지우면 기록이 사라집니다.

### 내보내기
1. 앱의 **백업** 화면(`/backup`)을 연다.
2. **전체 JSON 받기**를 눌러 파일을 저장한다. (카드만 엑셀 등에서 보고 싶으면 **카드만 CSV 받기**. CSV는 가져오기에 쓸 수 없다.)
3. 저장한 파일을 git 밖(외장 디스크, 클라우드 등 내가 믿는 곳)에 보관한다. **파일에 내 학습 기록이 그대로 들어 있으니 git에 올리거나 남에게 보내지 마세요.**

### 가져오기 (지금 데이터를 파일 내용으로 통째로 바꿈)
1. **백업** 화면에서 JSON 파일을 고른다. 이 앱이 만든 파일만 가져올 수 있고, 내용이 하나라도 틀리면 거부된다.
2. 미리보기(지금 → 가져온 뒤 카드·복습 기록 개수)를 확인한다.
3. "이해했어요"를 체크하고 **이 파일로 바꾸기**를 누른다.
4. 바꾸기 **직전**의 데이터는 자동으로 `data/backups/before-import-날짜시각.json`에 저장된다. 잘못 가져왔다면 그 파일을 다시 가져오면 돌아간다. (이 폴더도 git에 올라가지 않는다. 오래된 안전 백업은 직접 지워도 된다.)

### 자동 백업 (선택, macOS 전용)
평소에는 내보내기를 직접 눌러야 하지만, 예약을 설치하면 **7일에 한 번 자동으로** 백업합니다.
```
bash scripts/install-auto-backup.sh      # 설치 (한 번만)
cat ~/recallnote-backup.log              # 결과 확인 (OK 백업 완료 / SKIP ... / FAIL ...)
bash scripts/uninstall-auto-backup.sh    # 제거 (이미 만든 백업은 그대로 둠)
npm run backup:auto                      # 지금 한 번 직접 실행해 보기 (7일이 안 지났으면 건너뜀)
```
- 매일 12:40과 로그인할 때 확인하고, 마지막 백업 후 7일이 지났을 때만 `~/recallnote-backup/날짜폴더/recallnote-backup-….json`을 만듭니다. 최근 8개만 남겨요.
- 앱을 켜 두지 않아도 되고 DB는 읽기만 합니다. 이 파일은 **백업 화면의 가져오기**로 그대로 복원할 수 있어요.
- DB가 아직 없으면(앱을 한 번도 안 켰으면) 건너뛰고 로그에 `SKIP`을 남깁니다.
- 프로젝트 폴더를 옮기거나 Node를 바꿨다면 제거 후 다시 설치하세요.
- 같은 Mac 안의 백업이라서 Mac이 고장 나면 같이 사라져요. 가끔 `~/recallnote-backup/`을 외장 디스크 같은 곳에 복사해 두세요.

### 지금 당장 할 수 있는 백업: 파일 복사
앱을 끈 상태에서 `data/` 폴더를 통째로 다른 곳에 복사하세요. (`recallnote.db` 옆의 `-wal`, `-shm` 파일도 같이 복사하는 게 안전합니다. 앱을 끄면 보통 하나로 합쳐집니다.)
```
cp -R data ~/Desktop/recallnote-data-backup
```

## 5. 개인정보와 안전

- 데이터는 내 컴퓨터의 `data/recallnote.db` 한 파일에만 저장되고, **밖으로 전송되지 않습니다.** 앱은 외부 서버에 연결하지 않으며 글꼴도 앱 안에 들어 있습니다.
- **백업 파일과 `data/` 폴더에는 내 학습 기록이 그대로 들어 있습니다.** 남에게 보내거나 공개 저장소에 올리지 마세요. (이 프로젝트는 `.gitignore`로 막아 두었습니다.)
- 다른 웹사이트가 내 컴퓨터의 앱에 몰래 접근하지 못하도록, 앱은 `127.0.0.1`, `localhost`, `[::1]` 주소의 요청만 받습니다.
- 카드에 적은 글에 HTML이 있어도 실행되지 않고 글자 그대로 보입니다.

## 6. (선택) 학습 기록 파일에서 카드 만들기

공부하면서 `~/learning-log/confusions.md` 같은 **표 형식 메모 파일**을 쓰고 있다면, 거기서 카드 후보를 불러올 수 있습니다. 이 기능은 **없어도 앱은 평소처럼 동작합니다.**

1. 홈의 "새 학습 기록 N개" 또는 카드 목록의 "학습 기록에서 가져오기"로 `/learn`을 연다.
2. 만들 줄을 체크하고 **카드로 만들기**를 누른다. (안 만들 줄은 **건너뛰기**, 나중에 되돌릴 수 있어요.)
3. 한 번 처리한 줄은 다시 나오지 않아요. 앱은 이 파일을 **읽기만 하고 바꾸지 않습니다.**

- 표에는 `카드 질문`과 `내가 이해한 한 줄`이 모두 있는 줄만 후보가 됩니다. 필요한 열 이름과 예시는 [docs/developer.md](docs/developer.md#학습-기록-표-형식-선택-기능-learn)에 있어요.
- 파일 위치를 바꾸려면 `RECALLNOTE_LEARNING_LOG=/경로/파일.md npm run dev`처럼 실행하세요.

## 7. 자주 묻는 질문

**Q. 브라우저가 열리지 않아요.**
터미널에 나온 주소를 확인하세요. `3000` 포트를 다른 프로그램이 쓰고 있으면 다른 번호가 나올 수 있어요. 주소는 반드시 `127.0.0.1` 또는 `localhost`로 시작해야 합니다.

**Q. 컴퓨터 이름이나 IP 주소로는 왜 안 열려요?**
다른 사이트의 공격을 막으려는 안전 장치입니다. 일부러 막아 둔 것이니 `127.0.0.1`로 여세요.

**Q. 카드가 사라졌어요.**
삭제한 카드는 `/archive`(보관함)에 있습니다. 거기서 복원하세요. 데이터 파일을 지웠다면 백업 파일을 `/backup`에서 가져오면 됩니다.

**Q. 글자가 너무 작아요/커요.**
`/settings`에서 14~24px 사이로 바꿀 수 있어요.

**Q. 앱을 업데이트하면 내 기록이 지워지나요?**
아니요. 앱을 켤 때 DB 구조의 새 변경분만 자동 적용되고 기존 카드는 그대로 남습니다. 그래도 업데이트 전에는 백업을 한 번 받아 두는 것이 안전합니다.
